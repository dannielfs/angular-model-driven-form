API declarativa

O model também descreve a experiência do formulário.

Cada propriedade recebe apenas os metadados necessários. O builder cria o FormGroup , aplica os validators e o renderer Material escolhe o componente correto.

developer-profile.model.ts 
        

          export class

          DeveloperProfileForm

          {{ '{' }}

            @FormField

            ({{ '{' }}
              type: FormControlType.Text,
              label: 'Nome completo',
              validators: [Validators.required]
            {{ '}' }})

            fullName = '';

            @FormField

            ({{ '{' }}
              type: FormControlType.Checkbox,
              label: 'Apenas remoto'
            {{ '}' }})

            remoteOnly = false;

            @FormField

            ({{ '{' }}
              type: FormControlType.Text,
              label: 'Cidade',
              visibleWhen: value => !value.remoteOnly
            {{ '}' }})

            city = '';
          {{ '}' }}
